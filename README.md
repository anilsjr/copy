# Copy Button Project

# live link
anilsjr.github.io/copy [https://anilsjr.github.io/copy]



This project demonstrates a simple web page with a button that allows users to copy text from an input field to the clipboard. It uses HTML, CSS, and JavaScript along with Bootstrap for styling and Font Awesome for icons.

## Features

- Input field with default text
- Copy button with a Font Awesome icon
- Visual feedback when text is copied
- Responsive design using Bootstrap

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
- Font Awesome

## How to Use

1. Open the `index.html` file in a web browser.
2. Enter or modify the text in the input field.
3. Click the "Copy" button to copy the text to the clipboard.
4. The button text will change to "Copied!" for 1.5 seconds to indicate success.

## Files

- `index.html`: The main HTML file containing the structure of the web page.
- `css/style.css`: Custom CSS file for additional styling.
- `js/script.js`: JavaScript file containing the functionality to copy text to the clipboard.
